Student Fitness Tracker 

## 1. Project Description

Student Fitness Tracker is a web-based application designed to help students monitor and manage their daily fitness activities, workouts, nutrition and personal progress. The application uses a Strawberry Matcha theme with a simple and user-friendly interface.

This project was developed as a web application prototype using HTML, CSS, JavaScript and Bootstrap 5.

 2. Main Features

 2.1 Login Page
- Provides a login interface for users.
- Displays an error message when incorrect login details are entered.
- Includes a **Lecturer Quick Access** button that allows lecturers to access the dashboard directly without entering login credentials.

 2.2 Dashboard
- Displays an overview of fitness activities.
- Shows workout and calorie summaries.
- Provides quick access to different application sections.
- Includes a weekly activity chart.

2.3 Workouts
- Displays available workout activities.
- Allows users to explore different workout options.
- Shows workout progress.

 2.4 Nutrition
- Allows users to record their meals.
- Displays calorie and macronutrient information.
- Provides a meal history section.

2.5 Progress
- Displays fitness progress and activity summaries.
- Includes charts to visualise fitness information.
- Shows achievements and progress records.

2.6 Dark Mode
- Provides a dark mode option for a more comfortable viewing experience.

3. How to Access the Application

Users can access the application through two methods:

 Option 1: Lecturer Quick Access
1. Open the Student Fitness Tracker website.
2. Go to the login page.
3. Click the **Lecturer Quick Access** button.
4. The application will automatically display the dashboard.

Option 2: Demo Login
Use the following login credentials:

# 4. Technologies and Frameworks

The application was developed using:

- **HTML5** – Structures the web pages.
- **CSS3** – Styles the application interface.
- **JavaScript** – Provides interactive functionality.
- **Bootstrap 5.3.2** – Supports responsive layouts and components.
- **Bootstrap Icons** – Provides icons for the interface.
- **Chart.js** – Creates data visualisations and charts.

5. How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using a browser or the Live Server extension.
4. Ensure that an internet connection is available to load the external libraries.

 6. Important Notes

This project is a front-end web application prototype developed for academic purposes. The login system uses hardcoded demo credentials, and the Lecturer Quick Access feature is provided to simplify application demonstrations. These features do not represent secure, production-level authentication.
